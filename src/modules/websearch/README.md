# 联网搜索 🌐

给大肥鱼装上「查一下」和「点进去看」两件事：她能自己搜，也能把网页正文读回来。

## 做什么

- `qq_web_search`：搜一次，并且**自动把最相关那条的正文读回来**（可调 0～3 条、每条多少字）；
- `qq_web_read`：打开一个网页把正文读回来（搜到的链接、或者别人发给她的网址）。

## 三道闸（都在真正搜索之前）

1. **触发词**：对方最近几句话里出现「搜 / 查一下 / 帮我搜…」才放行（可自定义）；
2. **主人审批**：不是主人触发的搜索，会先在 QQ 里问主人，回「同意」才真的搜（超时自动拒绝）；
3. **限流**：每个聊天每分钟最多几次。

这三项都能在面板里关掉或调整。也可以开「她可以自己决定要不要搜」，让她遇到不懂或可能过时的东西自己查。

## 设置项

搜索源（默认 bing.com，也可填完整 `{q}` 模板）、自动读几条、每条最多多少字、触发词、审批与超时、每次最多几条、每分钟限额、群里能不能用。

## 会访问哪些网址

- 你设置的搜索站点（默认 `https://www.bing.com`）的搜索结果页；
- 搜索结果里点开的那几个网页（以及别人发给她的链接）。

**不会**上传你的任何配置、Cookie 或聊天记录；搜索历史只留在本机内存里给面板看（重启即清空）。
请求带的是浏览器 User-Agent，不做登录、不碰需要账号的页面。

## 依赖

无。用 Node 自带的 `fetch`。

## 面板

面板里有：当前状态、最近搜索、触发词测试、手动搜一次看结果（不会发到 QQ）。
